## 🎨 Design & Modern Web Standards

- **Semantic HTML5**: Full landmark structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<figure>`) with accessible ARIA tags and skip-to-content links.
- **Modern CSS3 Architecture**:
  - CSS Custom Properties (Design Tokens) with seamless **Dark and Light Theme** support.
  - Fluid typography using CSS `clamp()`, Google Fonts (*Plus Jakarta Sans*, *Instrument Serif*, *JetBrains Mono*).
  - Modern layouts via CSS Grid and Flexbox with zero layout shifts.
  - Micro-interactions, ambient radial glows, glassmorphism (`backdrop-filter: blur()`), and subtle hover animations.
  - Full mobile responsiveness tested from 320px screens up to 4K displays.
- **Zero Build Tools or Heavy Dependencies**: Runs directly in any browser and deploys natively on GitHub Pages without node/npm or compilation.
