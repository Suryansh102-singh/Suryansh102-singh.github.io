## Files

No JavaScript, framework, external font, or build tool is required.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000/`.

## Hosting

Publish with GitHub Pages using **Deploy from a branch → main → /(root)**. Check the generated website address after the deployment completes.
